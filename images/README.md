# Bildemappe for 04-moskeene

I denne mappen legges alle bildefiler og grafiske ressurser for nettsiden Moskeene.no.

## Anbefalte bilder og formater:

1. **`hero-banner.jpg` (Toppbilde):**
   * **Plassering:** Bakgrunn eller illustrasjon i `.hero-image-box`.
   * **Anbefalt format:** 16:9 bredformat (f.eks. 1200 x 675 px eller 1920 x 1080 px).
   * **Motiv:** Moskéarkitektur, fellesskap, lys eller interiør.

2. **Kort-bilder (4 stk):**
   * `kort-best-praksis.jpg` (f.eks. 600 x 400 px)
   * `kort-trosdialog.jpg` (f.eks. 600 x 400 px)
   * `kort-kalender.jpg` (f.eks. 600 x 400 px)
   * `kort-erfaringsbank.jpg` (f.eks. 600 x 400 px)

3. **Logo (valgfritt):**
   * `logo.svg` eller `logo.png`
